# 묘사 축문 웹 앱

`index.html`을 Chrome 또는 Edge에서 열거나 이 폴더를 정적 사이트로 호스팅한다. 서버나 Python은 필요하지 않다. 날짜는 양력 1900-01-31부터 2050-12-31까지 지원한다. 달력 자료는 Windows .NET `KoreanLunisolarCalendar`에서 추출한 음력 월별 초하루이며, 일진은 날짜 간의 일수 차이로 계산한다.

PDF로 저장 버튼을 누른 뒤 인쇄 창에서 대상을 **PDF로 저장**으로 선택한다. 축문별 A4 한 장씩 총 9장이며 한문을 세로로 인쇄한다. 인쇄용 한자에는 궁서풍의 cwTeX Q Kai ZH 글꼴을 적용하고, 한글은 기기의 궁서체를 사용한다. 웹 화면의 글꼴은 바뀌지 않는다. 인쇄용 글꼴은 [cwTeX Q 프로젝트](https://github.com/l10n-tw/cwtex-q-fonts-TTFs)의 SIL Open Font License 1.1에 따라 제공하며 라이선스는 `cwTeX-OFL.txt`에 있다. 브라우저와 글꼴에 따라 기존 Excel PDF와 세부 배치는 다를 수 있다.

매년 음력 평달 10월 초하루부터 첫 토요일을 계산한다. 연도 카드를 선택하거나 다른 양력 날짜를 입력하면 모든 축문에 반영된다.

각 축문에서 수정하기를 누르면 한문을 편집할 수 있다. 첫 줄의 `{{날짜}}`는 날짜가 삽입되는 자리다. GitHub에 저장할 때는 `shukjaechoi/myosa-choi` 저장소의 Contents 읽기·쓰기 권한을 가진 세분화된 개인 액세스 토큰이 필요하다. 토큰은 저장 요청에만 사용하며 저장하지 않는다. GitHub API가 `templates.js`를 main에 커밋하며, 원격 파일이 열린 이후 달라졌으면 덮어쓰지 않고 충돌을 알린다. 사이트에 반영되기까지 GitHub Pages 배포 시간이 걸릴 수 있다. 수정한 구절의 기존 음과 풀이는 그대로 두되 원문 변경에 따라 확인 필요로 표시된다.

기본 데이터에는 원본 축문의 가족 이름과 관계가 들어 있으므로 공개 저장소나 공개 Pages로 게시하면 누구나 볼 수 있다. 풀이와 음은 검토 가능한 초안이다.

검증: `node 검증.cjs`.
