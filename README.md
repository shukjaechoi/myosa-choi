# 묘사 축문 웹 앱

`index.html`을 Chrome 또는 Edge에서 열거나 이 폴더를 정적 사이트로 호스팅한다. 서버나 Python은 필요하지 않다. 날짜는 양력 1900-01-31부터 2050-12-31까지 지원한다. 달력 자료는 Windows .NET `KoreanLunisolarCalendar`에서 추출한 음력 월별 초하루이며, 일진은 날짜 간의 일수 차이로 계산한다.

PDF로 저장 버튼을 누른 뒤 인쇄 창에서 대상을 **PDF로 저장**으로 선택한다. 축문별 A4 한 장씩 총 9장이며 한문을 세로로 인쇄한다. 브라우저와 글꼴에 따라 기존 Excel PDF와 세부 배치는 다를 수 있다.

템플릿 설정의 내용은 브라우저 로컬 저장소에만 보관된다. 다른 기기와 자동 동기화되지 않고 브라우저 데이터를 삭제하면 사라진다. 기본 데이터에는 원본 축문의 가족 이름과 관계가 들어 있으므로 공개 저장소에 게시하면 누구나 볼 수 있다. 풀이와 음은 검토 가능한 초안이며 가문의 용례에 맞게 수정한다.

검증: `node 검증.cjs`.
